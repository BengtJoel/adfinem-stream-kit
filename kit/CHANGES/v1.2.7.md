**Customize overlays is in the Start menu.** After setup you no longer need the Setup program to change texts, alerts, the goal or sponsors: type **AD FINEM** in the Start menu and pick "AD FINEM - Customize overlays". The desktop shortcut and "Customize overlays.bat" in the kit folder still work too, and the Start menu folder also has the kit folder and Uninstall. Uninstall removes the Start menu folder.
