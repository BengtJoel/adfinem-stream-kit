**Customize overlays works from the Stream Deck.** Stream Deck's "Open" action does not always run .bat files, so the Customize key did nothing. The kit now has **Customize overlays.exe** (with the AD FINEM icon): the Stream Deck key, the desktop shortcut, the Start menu and Setup's button all use it, and it starts the editor without a console window. The editor opens in your browser as before and stops by itself after 45 minutes without use. "Customize overlays.bat" is still there as a fallback.

After updating, add the Stream Deck page again (Setup's last page > "Add Stream Deck page", or double-click "AD FINEM.streamDeckProfile" in the kit folder) so the key uses the new launcher.
