The first release of the AD FINEM Stream Kit.

**Windows:** download `AD-FINEM-Stream-Kit-Setup.exe` and run it. Windows may warn about an unknown publisher - click *More info* > *Run anyway*.
**Linux / manual:** download the `.zip`, unzip, run `bash install-linux.sh` (Linux) or `INSTALL.bat` (Windows).

- OBS scenes: Starting Soon, In-Game, BRB, Ending
- Intro plays when you go to In-Game, outro when you go to Ending, logo stinger for every other switch
- In-game overlay with webcam name tag and live raider.io progress
- Built-in Twitch alerts with sound (or StreamElements / Streamlabs)
- Rotating sponsors
- Overlay editor - OBS updates by itself
- Stream Deck page
- Twitch profile pack: avatar, banners, panels, sub badges
- Automatic update offers
