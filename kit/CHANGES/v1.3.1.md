**The Stream Deck Customize key opens the editor.** Stream Deck 7 reads the "Open" action as a command line, so a path with spaces (like "AD FINEM Stream Kit") has to be in quotes, otherwise it opens the wrong thing. The key now has the path in quotes. After updating, add the Stream Deck page again (Setup's last page > "Add Stream Deck page") and delete the older AD FINEM profiles in the Stream Deck app.
