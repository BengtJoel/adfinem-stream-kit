**Stream Deck keys show what OBS is doing.** With Elgato's free **OBS Studio** plugin installed in the Stream Deck app, the AD FINEM page now has a second look for every key that has a state:

- the **scene on screen** gets an accent frame and an **ACTIVE** tag
- **Mic** and **Desktop** turn grey with a red line and say **MUTED** when muted
- **Webcam**, **Sponsors** and **Alerts** say **HIDDEN** when they are off
- **Record** turns red while recording, **GO LIVE** turns red and says **LIVE** while you stream

Setup finds the plugin by itself. If it is missing, the last page of Setup has a **Get the OBS plugin** button: click "Get" on Elgato's page and Setup updates your Stream Deck page as soon as the plugin is installed. Without the plugin the keys work like before (hotkeys, one look).

With **both** looks installed the profile has two pages, one per scene collection (AD FINEM and AD FINEM Forever), with Forever icons on the Forever page. The bottom-left key switches between them.

Webcam, sponsors and alerts are now always kept the same in every scene: hide one in any scene, from OBS or the Stream Deck, and the others follow.
